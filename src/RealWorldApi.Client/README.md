# RealWorld API Client

This is the Vite/Solid SPA for `RealWorldApi.Core`.

Run it locally:

```bash
pnpm dev
```

Build it for the API to serve:

```bash
pnpm build
```

The production build writes to `../RealWorldApi.Core/wwwroot`, so the API can
serve the compiled client as static files. The root repository README has the
full deployment notes.

Routes are managed by TanStack Router using files in `src/routes`. The generated
`src/routeTree.gen.ts` file is expected and should be regenerated by the router
plugin when routes change.
